TWICE with different meanings — once for the main decals (Police text, Public Order
Management text, chequer band, Kings Crest) and again for the reflective strip specs
("4x CHECKS top&bottom 2900mm" = DRIVE-3/PASS-3; "2x CHECKS top&bottom 1500mm" =
DRIVE-4/PASS-4). The source document's own reflective page (page 4) confirms this:
it divides each side's single chequer band (already tagged as PASS-3/DRIVE-3 below)
into 3 visual zones ("CHEQUERS DRIVE 1/2/3", "CHEQUERS PASS 1/2/3") that correspond to
the 2900mm+2900mm+1500mm length breakdown, but does not give them separate point
codes distinct from the main-page PASS-3/DRIVE-3/DRIVE-4/PASS-4 — and those code
names already collide with the main-page crest codes. To avoid inventing or
duplicating codes, these zone subdivisions are documented here rather than given
extra point tags; only FRONT-1 and REAR-4/REAR-5 (which do not collide with any
main-page code) are tagged as distinct reflective points.
