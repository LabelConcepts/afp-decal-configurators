AFP Toyota LandCruiser Sahara - Tailgate design, Kings Crest
Source PDF: "AFP - SAHARA LANDCRUISER - TAIL GATE - KINGS CREST - FITTING.pdf"
(8 pages). This single PDF actually contains TWO distinct checklists bundled
together, and afp_vehicles.json's "landcruiser_sahara_tailgate" entry merges
both into one 15-item list:
  - Page 1 (checklist) + Page 2 (VISUAL render) = "SAHARA - GENERAL DUTIES /
    KINGS CREST" design: FLEET NUMBER RP60, PASS-1..4, FRONT-1..4 (9 items,
    matches that page's own "Total Number of Parts: 9").
  - Page 3 (checklist) + Page 4 (VISUAL render, with the doc's OWN pre-drawn
    leader-line labels "LAND F1"/"LAND F2"/"LAND F3"/"LAND F4"/"LAND R1") =
    plain "GENERAL DUTIES" reflective-tape design: SIDE-1, REAR-1, LAND F1-4
    (6 items, matches that page's "Total Number of Parts: 13" once the "8x"
    SIDE-1 quantity is expanded).
  - Pages 5-8 are real "INSTALL PHOTO" shots of the finished vehicle (side,
    rear-3/4, front, rear) showing both decal sets already combined on one
    real car - used only to visually confirm the designs are genuinely
    fitted together on one vehicle, not to pull coordinates from (no second
    side/angle photo exists for those real photos, so they were not usable
    for per-item pixel measurement).
