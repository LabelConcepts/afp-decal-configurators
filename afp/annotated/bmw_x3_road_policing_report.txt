count_mismatch flag: the checklist page states "Total Number of Parts: 13 +
REFLECTIVE STRIPS" while extraction produced 15 json items (13 core decals +
SIDE-1 + SIDE-2). Having now looked at the actual checklist text, this is
explained, not an extraction error: the checklist lists "2x SIDE 2200mm x
80mm..." and "2x SIDE 3450mm x 33mm..." as its own two reflective-strip line
items (quantity 2 = fitted once per side, pass+drive), on top of the 13 core
decal lines (3 Pass + 3 Drive + 7 Rear = 13). So 13 "core" + 2 "reflective
strip" line items = 15 json entries, which is internally consistent; the
doc's own "13 + REFLECTIVE STRIPS" total just doesn't spell out the +2.
Visually confirmed both SIDE-1 and SIDE-2 are real, distinct decals (two
parallel yellow stripes of different thickness running the length of each
side - see SIDE-1/SIDE-2 below) - so nothing was mis-extracted.
