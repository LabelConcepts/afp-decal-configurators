no way to independently verify 12 distinct point-coordinates for strip segments that
don't visually separate into 12 discrete points. The item list itself reuses the main
decal code names (PASS-1, DRIVE-1, REAR-1, etc.) for this second group, which would
collide with the main-page tags already placed above if forced onto the same image.

not done, per project rules against guessing. Only the 13 genuine, independently
measured main-page items are tagged.
